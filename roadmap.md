# Deferred dogfood feedback

Revisit these only if three weeks of use show they block capture or recall. See [product intent](docs/product-intent.md).

- **Pin contacts:** The dogfood note itself found that a new event makes the fake contact easy to find. Wait for a real recall problem.
- **Hide irrelevant imported contacts:** Doctors, code senders, and fake contacts add noise. If this blocks finding people, add a persistent hide choice that survives contact refresh and backup/restore.
- **Commonality suggestions:** Wait for evidence from tags and relationships before adding comparisons.
- **Relationship metadata:** Keep last seen derived from events; add fields only for a concrete recall need.
- **Fact dates:** Use the recorded date until pilot use shows that an editable date is needed.
- **Advanced tags:** Defer hierarchies, bulk editing, and other management tools.

# Dogfooding week

Use this week to learn whether capturing context makes it easier to remember
people later. Follow-ups are optional. There is no daily quota.

## Before starting

- Use the validated debug APK identified in the accompanying validation report.
- If updating an existing phone installation, keep its signing key and data. Do
  not uninstall to resolve a signature mismatch without first exporting a backup.
- Add a person manually or optionally import Android contacts. Denying Contacts
  permission must not prevent manual use.
- Choose a backup folder if you want daily backups. Backups contain unencrypted
  private notes; choose a location you trust. Keep a manual export before changing
  builds or trying a restore on real data.

## During ordinary use

- Capture something worth remembering, including a longer note when useful.
- Later, search for a detail rather than relying on remembering the person's name.
- Open the person's history and check that it supplies the context you expected.
- If you explicitly want to follow something up, add it; mark it done when useful.
- Try your usual text size and keyboard. Notice unnecessary taps, confusing words,
  hidden actions, lost context, or uncertainty about whether something saved.

## Record friction

Keep a short note for each problem:

```text
Wanted to:
What happened instead:
Could I finish? How?
Screenshot (optional):
```

For lost or incorrect data, stop experimenting with that record and export a
backup before trying recovery. Use fictional data for deliberate destructive tests.

## After the week

Review repeated friction and examples of successful recall. Prioritize fixes that
make capture or retrieval more dependable. Choose new features only when actual
use identifies a missing capability.

Installation on a physical phone is a separate handoff; automated and exploratory
validation use the dedicated host emulator.
